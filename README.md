# ARUCHERU

## "Arucheru" is a game made in the context of a game development class. 

## 🏹 Pitch
You play a little archer that must defend his realm from monsters.

# 🏹 Technical considerations
Estimated game time : 5 min
Controls : Keyboard
Keyboard controls : Move with ZQSD, Dash by double tapping, Fire with space, Switch weapon wit E
Language : English
